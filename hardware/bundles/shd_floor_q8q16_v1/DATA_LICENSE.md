# SHD data attribution

The unlabeled event inputs in this bundle are derived from the Spiking
Heidelberg Digits dataset by Benjamin Cramer, Yannik Stradmann, Johannes
Schemmel, and Friedemann Zenke.

The source dataset is available from the Zenke Lab:

https://zenkelab.org/resources/spiking-heidelberg-datasets-shd/

The dataset is distributed under the Creative Commons Attribution 4.0
International License:

https://creativecommons.org/licenses/by/4.0/

PINES bins each event sequence into 50 binary timesteps over 1.4 seconds and
retains 700 input channels. The hardware bundle contains only the frozen
unlabeled certificate-audit subset. Dataset labels and speaker metadata are not
included.
