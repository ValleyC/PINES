# SHD data attribution

The event inputs are derived from the Spiking Heidelberg Digits dataset by
Benjamin Cramer, Yannik Stradmann, Johannes Schemmel and Friedemann Zenke.

Source: [Zenke Lab SHD dataset](https://zenkelab.org/resources/spiking-heidelberg-datasets-shd/).
License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

PINES bins each sequence into 50 binary timesteps over 1.4 seconds and preserves
700 input channels. This bundle contains eight training-pool development inputs
and two disjoint sets of 861 held-out test inputs. Labels and speaker metadata
are omitted. The preprocessing is a modification of the original event data.
