\section{A four-level transport certificate}

\subsection{Exact and per-input certificates}

The first level searches a library of proved parameter transports. Structural
identity is the trivial member. Any nontrivial mapping must preserve the complete
transition, including reset and queues, and survive symbolic derivation,
exhaustive small-state checking, and adversarial trace search.

For a general bounded family, we unroll the recurrent network for $T$ steps and
propagate lower and upper state sets. Affine maps use sign-split interval
arithmetic. Fixed-point rounding is enclosed at integer bin boundaries; wrapping
that may cross the representable range expands to the full numeric domain.
Delays are queues of abstract states. At a threshold discontinuity, the analyzer
splits quiet and spiking branches, applies the appropriate reset, and conservatively
merges them. Discrete semantic variants are analyzed separately and their output
sets are not mixed before testing the decision. Continuous uncertainty within a
single discrete member is conservatively merged.

For reference prediction $c_0$ and member-specific target logit intervals
$[\ell_{c,s}(x),u_{c,s}(x)]$, input $x$ is certified if
\begin{equation}
  \ell_{c_0,s}(x) > \max_{c\ne c_0} u_{c,s}(x)
  \qquad \text{for every discrete member }s.
\end{equation}
The condition proves an unchanged argmax for every semantics member represented
by the abstract family. Checking the inequality after globally joining mutually
exclusive members is sound but unnecessarily stronger and is not used by the
canonical engine. Exact enumeration is also available when the declared family
itself is finite; a MILP checker is planned as a tighter small-network oracle.

We also test a decision-level correlated interval domain. Instead of bounding
each output independently, it propagates every reference-versus-competitor
margin using the shared uncertain spike vector. This prevents the same spike
from independently minimizing the reference logit and maximizing a competitor.
The current sound implementation covers floating-point state execution; fixed-
point output rounding requires an additional correlated accumulator state.
An adaptive cover can then retire any proved timestep/threshold sub-box and
bisect only unresolved leaves. Its leaves always cover the original rectangle;
the input is certified only if every leaf is proved. Covered parameter volume
is a tractability diagnostic, not a probability over target semantics.

Our tighter recurrent domain represents each hidden state as an affine form over
two shared generators---timestep and threshold scale---plus an independent box
residual. Linear recurrence preserves the generators exactly. Forward-Euler
products retain their first-order shared terms and add a proved remainder bound;
only threshold-uncertain spikes are relaxed to $[0,1]$. Pairwise output margins
are accumulated in the same relational domain. Forward Euler is bilinear in the
shared timestep generator. For exponential Euler, a first-order exponential
form plus a second-derivative remainder encloses the decay factor. Declared
synaptic and output delays are explicit queues of affine states. Fixed-point
numeric rules remain delegated to the interval engine.

Every declared float32 conversion of current, state, output contribution, and
accumulated logit adds the conservative radius
$\epsilon\max(|\ell|,|u|)+\eta_{\min}$. Output and accumulator roundoff are
charged to direct pairwise margins rather than formed by subtracting independent
logit boxes; this preserves cancellation of shared spike terms. The analyzer's
own binary64 additions, products, dot products, exponential approximation, and
affine evaluation receive standard $\gamma_n$ error terms, and reported lower
and upper endpoints are advanced outward with \texttt{nextafter}.

For an unresolved affine leaf, we expose a recurrent guard enclosure
$c+g^\top\epsilon\pm r$. Convex polygon clipping partitions the semantic domain
into robust quiet, residual-band, and spiking regions. Affine bounds and product
remainders are recentered and recomputed over each polygon; the remaining region
uses width-scaled axis refinement after a declared guard-cut budget. Polygon
areas are checked to cover the parent exactly, and only zero unresolved area
produces a certificate.

Guard cuts alone can leave a vanishingly small but topologically persistent
residue.  We close such regions with a local branch oracle.  Conditional on a
previous spike vector, the recurrent current is exact and the hidden state
remains an affine enclosure over the same polygon.  At each guard the oracle
keeps the forced outcome when its sign is robust and enumerates both outcomes
when its enclosure crosses zero.  It deliberately retains infeasible spike
assignments rather than relying on an unsound path-pruning heuristic.  Thus the
enumerated trace set overapproximates all executions in the polygon. For either
declared reset rule, each completed spike trace has an exact output class; the
polygon is certified only when every retained trace predicts the reference
class. Exceeding the branch cap is inconclusive.

The adaptive hybrid first applies this branch oracle to the current polygon.  A
completed single-class enumeration retires the polygon immediately.  Otherwise
the affine analyzer supplies a sound guard-band cut, with width-scaled axis
bisection as a fallback, and the oracle is retried on each child.  The final
polygons must cover the root rectangle and every positive-area leaf must be
retired.  This composition is important: branch enumeration on the full box can
hit the cap, while refinement can isolate the few guards responsible for the
combinatorial growth.

\begin{proposition}[Sound local branch closure]
For one deterministic floating-point member using forward or exponential Euler,
finite declared delivery queues, and a convex parameter polygon $P$, the
completed local oracle's prediction set contains the prediction of every
execution with parameters in $P$.
\end{proposition}
\begin{proof}
Induct on time.  Initially the single affine state contains the exact zero
state.  Assume the retained branches contain the prefix of an arbitrary concrete
execution.  Affine integration and the declared rounding envelope contain its
pre-threshold voltage.  If the guard sign is robust, the oracle takes the same
outcome; if it is uncertain, the oracle retains both outcomes and hence retains
the concrete one.  The corresponding reset, recurrent update, and queued
delivery preserve the enclosure.  Thus some retained branch contains every
concrete prefix.  At the
finite horizon its spike trace has the same accumulated output and its class is
included in the reported prediction set.
\end{proof}
Because polygon cuts form an area-checked cover, applying the proposition to
every retired leaf proves the hybrid certificate.  The implementation is also
tested against randomized recurrent executions; sampled testing is not used in
the proof.

For reset-to-value execution at a fixed timestep, threshold does not enter the
state update conditional on a spike trace. We exploit this to exhaust every
binary64 shared-threshold scale in a closed interval. The exact emulator trace
defines a contiguous validity cell: quiet guards impose a lower scale and
spiking guards an upper scale. Monotone search uses the emulator's actual
floating-point multiplication and comparison, and a work queue covers the
entire representable interval. Exhausting the cell budget is inconclusive. This
oracle is exact for a fixed timestep, not for the continuum between timestep
slices.

We also implement a path-separated diagnostic domain for a single zero-delay
member. It enumerates possible spike vectors, propagates a separate interval
state for each path, and merges only paths with identical current spikes and
accumulated logits. Exceeding a declared state cap returns \emph{inconclusive},
never certified. This domain is sound but remains a feasibility prototype: it
does not yet compress symbolic parameter guards or support delayed-state merge
keys.

\subsection{Distribution certificate}

Static certification need not cover every input. On an untouched unlabeled audit
sample $x_1,\ldots,x_n$, define
\begin{equation}
  D_i(s)=\mathbf{1}[F_{s_0}(x_i)\ne F_s(x_i)].
\end{equation}
For $k_s=\sum_i D_i(s)$, we use the exact one-sided Clopper--Pearson limit
$U_s(\alpha)$. With $m$ target family members, Bonferroni correction at
$\alpha=\delta/m$ yields simultaneous coverage, and
$U_{\TRef,\Emu}=\max_s U_s(\delta/m)$ for a fixed but unknown declared target.

\begin{proposition}[Accuracy-change bound]
For arbitrary labels $Y$ and paired predictions from classifiers $f$ and $g$,
\[
|\Pr[f(X)=Y]-\Pr[g(X)=Y]|\leq \Pr[f(X)\ne g(X)].
\]
\end{proposition}
\begin{proof}
Pointwise, the two correctness indicators can differ only when the predictions
differ. Taking expectations and applying $|\mathbb{E}Z|\leq\mathbb{E}|Z|$
proves the statement.
\end{proof}

\begin{proposition}[Sharpness without labels]
For any paired predictors $f,g$ with disagreement probability $d$, there are two
label distributions consistent with the same unlabeled prediction pairs for
which the signed accuracy change is $d$ in either direction.
\end{proposition}
\begin{proof}
Set $Y=f(X)$. Then $f$ has accuracy one and $g$ has accuracy $1-d$, so the
reference-favoring change is $d$. Setting $Y=g(X)$ reverses the roles. The
unlabeled joint distribution of $(f(X),g(X))$ is unchanged.
\end{proof}

Consequently, no method using only paired predictions can provide a uniformly
smaller distribution-free upper bound on absolute accuracy change. Operational
tightening requires explicit additional information or assumptions, such as a
restricted label mechanism, a small labeled audit, or a validated structural
relationship between disagreement direction and correctness.

\subsection{Physical certificate}

An emulator cannot certify unmodeled hardware behavior. We therefore execute an
unlabeled canary and estimate paired emulator--hardware disagreement. Splitting
failure probability across the two estimates gives
\begin{equation}
U_{\mathrm{total}}=\min\{1,
U_{\TRef,\Emu}(\delta/2)+U_{\Emu,\Hw}(\delta/2)\}.
\end{equation}
Without the second term, the report is marked \emph{conditional on emulator}.
For nondeterministic hardware, the primary sample contains independent
$(x,\text{run})$ pairs. Repeated execution of selected inputs characterizes
run-to-run variance but cannot replace those pairs.
