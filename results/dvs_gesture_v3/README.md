# DVS Gesture manuscript evidence

- `software_matrix_rows.csv` and `software_matrix_summary.json` contain the
  five-seed, ten-target results used in Table I.
- `finite_family_rows.csv` and `finite_family_summary.json` contain exact
  16-member family results used in Table II.
- `repair_floor_task_tuned_clean_v5_rows.csv` and its summary contain the
  fixed-point repair comparison used in Table IV.

The DVS Gesture results are marked as development evidence in the manuscript
because the official test performance informed selection of the reference
pipeline before the target semantics were frozen.
